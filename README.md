# DayMark

> 每日打卡 · 待办清单 · 日程管理 —— 桌面应用（含便携版），基于 React + Electron，支持坚果云 WebDAV 数据同步。

DayMark 是一款本地优先（数据不出本机）的日常管理工具，帮助你养成打卡习惯、管理待办事项、查看日程与统计。

***

## 一、功能特性

| 模块           | 说明                                   |
| ------------ | ------------------------------------ |
| 打卡（Checkin）  | 创建打卡项目，按天标记完成/未完成，日历视图查看完成情况         |
| 统计           | 完成天数、完成率、连续打卡天数、最长连续天数；月/季/年图表       |
| 待办（Todo）     | 多行动态待办项，支持截止时间、完成确认、编辑删除             |
| 日程（Schedule） | 按日期查看打卡、待办与行动的集中视图；右栏另有「提醒」列出未来 7 天内待完成的行动项 |
| 数据管理         | 一键导出 CSV / 备份 JSON、从备份恢复、WebDAV 同步面板 |
| 数据同步         | 坚果云 WebDAV（应用密码认证），支持手动推/拉与自动同步      |

***

## 二、界面与导航

底部导航栏（从左到右）：**日程 · 打卡 · 待办**，右侧为 **数据管理** 入口。

- **日程**（`#/schedule`）：默认首页，按日期聚合显示打卡、待办与行动记录；右栏底部另有 **提醒**，列出未来 7 天内待完成的「行动」项，按紧急度排序（剩余天数越少越靠前，**逾期未完成的自然置顶**并标红），可直接在提醒里勾选完成。

- **打卡**（`#/checkin`）：打卡项目管理 + 当日打卡 + 右侧统计卡片与月/季/年图表。

- **待办**（`#/todos`）：待办清单，支持勾选完成、设置截止、编辑与删除。

- **数据管理**：导出/导入备份、查看汇总、配置 WebDAV 同步。

## 四、快速开始（开发）

环境要求：Node.js 18+。

```bash
npm install          # 安装依赖
npm run dev          # 启动 Vite 开发服务器（http://localhost:3000）
npm run electron:dev # 以 Electron 桌面模式开发调试（自动起 dev server）
npm run hooks:install # 手动补装提交前钩子（npm install 时已自动装好）：每次 commit 前自动跑 npm run verify
```

> Electron 开发模式启动后，本地数据通过主进程落盘（`daymark-snapshot.json`），而非浏览器 localStorage。
>
> 开发端口固定为 3000 且不容让位（`strictPort`）：端口被占用时直接报错，而不是静默换到 3001 —— 桌面模式写死了加载 `localhost:3000`，换端口会让窗口显示别的页面。
>
> 桌面版同一时间只允许一个实例（安装版与便携版共用同一份用户数据，双开会互相盖写数据文件）；重复启动只会把已有窗口调到前台。

### 常用脚本

| 命令                         | 作用                                     |
| -------------------------- | -------------------------------------- |
| `npm run dev`              | Vite 开发服务器                             |
| `npm run build`            | 构建 Web 版到 `dist/`                      |
| `npm run build:standalone` | 构建并合并为单文件 `dist/index-standalone.html` |
| `npm run build:electron`   | 完整构建并打包桌面版（NSIS 安装包 + 便携版）             |
| `npm run hooks:install`    | 手动补装提交前跑 verify 的本地 git 钩子（`npm install` 已自动装好） |
| `npm run verify`           | 全量回归校验（下列六套依次跑完，任一套失败即整体失败）            |
| `verify:backup`            | CSV / JSON 备份与恢复的往返一致性、公式注入护栏            |
| `verify:stats`             | 打卡统计口径（单项目 / 多项聚合 / 连续天数）                |
| `verify:webdav`            | WebDAV 协议、冲突决策、备份留档、请求超时、目录名编码          |
| `verify:todo`              | 待办「完成记录编辑」不翻转状态、不清空 STAR 字段、过期判定       |
| `verify:persistence`       | 落盘时序：回填完成前不落盘、防抖合并、关窗同步兜底             |
| `verify:config`            | `daymark-config.json` 读写、自定义服务器地址、密码加密 |

> 六套脚本源码在 `.workbuddy/verify-*.mjs`，用 esbuild 打包后以纯 Node 运行：渲染层模块的导入路径不带扩展名，直接 `node` 跑会解析失败，因此统一过 esbuild。它们不依赖 Electron，改完 `storage / persistence / webdav / config` 任一处都请先跑 `npm run verify`。

> 依赖都写在 `devDependencies` 是有意的：渲染层由 Vite 打包成单文件 HTML，主进程只用 `electron` 与 Node 内置模块，运行时不读 `node_modules`，所以这些库都属构建期依赖。把它们挪进 `dependencies` 反而会让 electron-builder 将整个 `node_modules` 打进 asar，包体显著变大。

## 五、数据存储与位置

**本地优先**：所有数据默认保存在本机，不经过任何第三方服务器（坚果云仅在你主动配置同步时使用）。

| 形态            | 数据位置                                                           |
| ------------- | -------------------------------------------------------------- |
| Web 版（浏览器）    | 浏览器 `localStorage`（按浏览器隔离）                                     |
| 桌面版（Electron） | 系统用户数据目录 `userData/`                                           |
| 具体文件          | `daymark-snapshot.json`（业务数据）、`daymark-config.json`（WebDAV 配置，应用密码加密存储） |

Windows 下的实际目录名取自 `package.json` 的 `name`（不是安装程序显示的 DayMark）：

```
%APPDATA%\daily-checkin-app\
```

> 桌面版与浏览器版数据互相隔离，跨形态迁移请使用「数据管理 → 导出 JSON 备份 → 导入」流程。

## 六、坚果云 WebDAV 数据同步（桌面版）

DayMark 通过坚果云 WebDAV 实现云端备份。自动同步只做**上传**（把本机较新的数据推到云端），换设备后取回数据仍需在新设备上手动点「下载」。

### 第一步：获取坚果云应用密码

1. 登录 [坚果云官网](https://www.jianguoyun.com)，进入 **账户信息 → 安全选项 → 第三方应用管理**。
2. 添加应用（如 `DayMark`），生成**应用密码**（注意：不是登录密码）。

### 第二步：在应用内配置

1. 点击底部导航「数据管理」。
2. 填写：坚果云注册邮箱（或用户名）、应用密码。
3. 可选：同步目录（默认 `DayMark`）、WebDAV 服务器地址（留空即使用 `https://dav.jianguoyun.com/dav/`，仅在自建 WebDAV 时需要填）、开启自动同步。
4. 点击「测试连接」验证，然后「上传」或「下载」。

### 同步机制

- 同步前会**比较本地与云端数据的更新时间**，以较新的一份为准；较旧的一方被覆盖属正常，不做备份。

- **不会静默丢掉较新的一份**：手动「上传」时若云端更新、或「下载」时若本机更新，都会先弹出数据冲突提示并中止，需要你明确选择。

- 确认强行覆盖后，被覆盖的那一份会自动留档：本机数据存为 `%APPDATA%\daily-checkin-app\daymark-snapshot.conflict-<时间>.json`（最多保留最近 10 份），云端数据存为同步目录下的 `daymark-snapshot.cloud-<时间>.json`。留档文件可用「数据管理 → 从备份恢复」取回。

- 开启自动同步后，本地数据变更会自动推送到云端（自动同步只在「云端较旧」时上传，不会触发冲突）。

- 同一时刻只运行一个同步任务：手动推/拉与自动同步相遇时，后到的一方会收到「已有同步任务在进行」提示，不会交错读写同一份快照。

- 每次请求 20 秒超时：网络半开或地址写错时会报「超时」并恢复按钮，而不是一直停在「处理中…」。

- 凭据仅保存在本机 `daymark-config.json`，界面上永不回显。应用密码先经操作系统提供的加密（Windows 下绑定当前用户账户的 DPAPI）再写入 `passwordEnc` 字段，文件里不留明文；旧版本存下的明文会在下一次写入时自动转成密文。若换了机器或换了 Windows 账户导致密码解不开，会显示为「未配置」，重新填一次即可。

- 同步目录名可以带空格、中文、`#` 等字符，拼接云端地址时会自动按 URL 段编码。

> 数据迁移：换电脑或重装系统后，装好 DayMark → 数据管理 → 配置同一账号 → 「下载」即完成恢复（本机为空时不会提示冲突，直接下载）。

## 七、数据管理与迁移

数据管理面板支持：

- **导出 CSV**：单文件，含打卡项目、打卡记录、待办事项三个区块，可直接用 Excel 打开。内容以 `=`、`+`、`-`、`@` 开头的单元格会加一个前置单引号，防止被 Excel 当公式执行（用 DayMark「从备份恢复」读回时会自动脱掉这层护栏，内容不变）。

- **导出/备份 JSON**：无损备份，用于跨设备、跨浏览器迁移。

- **从备份恢复**：选择 JSON 或 CSV 备份文件一键恢复，支持合并与覆盖两种模式。

- 支持手动推/拉到坚果云（见上节）。

***

## 八、统计口径

完成率的分母只包含**「当天已经存在的打卡项」**，且**还没到来的日子不参与统计**：

- 项目创建之前的那些天不算「未完成」，否则晚建的项目会被系统性拉低完成率。
- 月 / 季 / 年视图与「全部项目」聚合卡片用的是同一套口径；跨年视图也不会把未来的月份算成一堆 0%。
- 单项目视图与聚合视图的 `total` 可以直接相加对齐（回归脚本 `verify:stats` 锁住了这条不变式）。

## 九、常见问题

| 问题              | 解决方法                      |
| --------------- | ------------------------- |
| 便携版无法运行 / 被杀毒拦截 | 自解压可执行文件被部分安全软件误报，添加信任后重试 |
| 同步提示 401        | 应用密码错误或未开启；请重新生成坚果云应用密码   |
| 同步提示 404        | 云端目录中尚无数据文件，属正常提示，先「上传」即可 |
| 同步提示「数据冲突」      | 两侧各有改动，程序已中止以免丢数据；按提示选方向，确需强行覆盖时较新的一份会自动留档为 `daymark-snapshot.conflict/cloud-*.json` |
| 桌面版与浏览器版数据不一致   | 两者存储隔离，用「导出 JSON → 导入」迁移  |
| 自动同步未生效         | 确认已开启「自动同步」且账号密码已保存       |
| 换机 / 重装后配置里显示「未配置密码」 | 应用密码绑定了原系统的用户账户，解不开属正常；重填一次即可 |
| 双击第二个 DayMark 没反应 | 已有一个实例在运行（安装版与便携版共用同一份数据），系统会把已有窗口调到前台 |

## 十、目录结构

```
DayMark/
├── src/                  # React 前端源码
│   ├── pages/            # 打卡 / 待办 / 日程页面
│   ├── components/       # 组件（导航、图表、弹窗、同步面板等）
│   └── utils/            # 存储 / 持久化桥 / 备份导出 / 颜色工具
├── electron/             # Electron 桌面层
│   ├── main.js           # 主进程：窗口、快照落盘、同步 IPC
│   ├── preload.cjs       # 安全桥接 window.daymark API
│   ├── config.js         # daymark-config.json 读写（纯 Node，可脱离 Electron 测试）
│   └── webdav.js         # 坚果云 WebDAV 同步核心
├── .workbuddy/           # verify-*.mjs 回归校验脚本与开发笔记
├── scripts/              # 开发辅助脚本（含 git-hooks 提交前钩子）
├── dist/                 # Web 构建产物（可再生）
├── release/              # 桌面打包产物（安装包 / 便携版 / win-unpacked）
├── archive/              # 历史产物归档（旧版本构建）
├── index.html            # Vite 入口
├── index-standalone.html # 桌面版实际加载的单文件产物（由 build:electron 从 dist/ 复制）
└── package.json          # 项目配置与脚本
```
